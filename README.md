# SIGI

Sistema de gestão para restauração e bar, com frontend React/Vite, API Flask/Socket.IO e MySQL/MariaDB.

Consulte o [guia de instalação e operação](GUIA_INSTALACAO_E_OPERACAO.md) para preparar uma máquina nova, configurar a base de dados, iniciar o backend/frontend e diagnosticar pesquisa, notificações, SMS e WebSocket.
